# GymCoach — план доработок UX тренировки

Статус: реализовано, проверено и задеплоено на Renat VPS.

Последнее обновление: 2026-09-20

## 1. Старт свободной тренировки без промежуточного экрана

Текущее поведение:
- «Начать свободную тренировку» создаёт сессию;
- затем показывается пустой экран «Свободная тренировка»;
- пользователь отдельно нажимает «Добавить упражнение».

Нужное поведение:
- при нажатии «Начать свободную тренировку» сразу открывать окно выбора первого упражнения;
- промежуточный пустой экран свободной тренировки при старте не показывать;
- пока первое упражнение не выбрано, Session вообще не создавать;
- если пользователь закрыл picker или вернулся назад без выбора упражнения, вернуть его на главную;
- в этом случае никакой пустой/незавершённой свободной тренировки в БД не должно появляться.

## 2. Picker упражнений — убрать технический текст

Убрать из интерфейса фразу:
> «Сначала идут упражнения, которые вы уже выполняли. Поиск и фильтры сохраняют этот порядок.»

Сама логика сортировки остаётся:
- после применения поиска/фильтров сначала показывать упражнения, которые выполнялись хотя бы в одной тренировке;
- затем упражнения, которые ещё никогда не выполнялись;
- визуально это один непрерывный список, без отдельных секций/заголовков.

## 2.1. Миниатюры упражнений в picker

В окне выбора/добавления упражнения в каждой строке списка показывать небольшую миниатюру изображения упражнения слева от текста.

Нужный вид строки:
- слева — маленькая квадратная/скруглённая миниатюра упражнения;
- рядом — название упражнения;
- справа — существующая информация о количестве тренировок, если она показывается;
- высота строки и размеры миниатюры должны оставаться компактными и удобными для мобильного экрана.

Если у упражнения нет изображения:
- использовать нейтральный placeholder/fallback того же размера;
- не сдвигать текст и не менять выравнивание списка.

Миниатюры нужны и при первом выборе упражнения для свободной тренировки, и при добавлении следующих упражнений во время любой активной тренировки.

## 3. Кнопка добавления упражнения как карточка в горизонтальной ленте

Текущее поведение:
- под горизонтальной лентой упражнений находится отдельная широкая кнопка «Добавить упражнение».

Нужное поведение:
- убрать отдельную широкую кнопку;
- после последней карточки упражнения в горизонтальной ленте добавить отдельную карточку-кнопку;
- размеры/форма карточки примерно такие же, как у карточек упражнений в этой ленте;
- внутри только крупный символ «+»;
- текста «Добавить упражнение» на карточке не должно быть;
- нажатие открывает picker добавления следующего упражнения.

## 4. Верхняя зона тренировки как меню управления

Зона, где отображаются:
- тип/название тренировки (например «Свободная тренировка» или название дня программы);
- строка текущего упражнения (например «Упражнение 1/1 · Жим лёжа · Штанга»);

должна стать интерактивной.

Нужное поведение:
- вся эта текстовая зона кликабельна;
- рядом справа, чуть левее текущего крестика, добавить иконку гаечного ключа;
- нажатие на текстовую область или гаечный ключ открывает меню «Управление тренировкой».

### Меню «Управление тренировкой»

В меню нужны действия:
1. «Завершить тренировку»;
2. «Отменить тренировку» / «Сбросить тренировку».

Пауза тренировки не нужна.

### Защита при отмене/сбросе

При выборе отмены/сброса:
- открыть отдельное подтверждение;
- явно предупредить, что данные текущей тренировки будут удалены/сброшены;
- финальная destructive-кнопка первые 3 секунды неактивна;
- спустя 3 секунды кнопка становится доступна;
- это защита от случайной отмены тренировки.

## 5. Удалить нижнюю панель управления тренировкой

Полностью убрать нижнюю строку/панель, где сейчас находятся действия вроде:
- назад;
- вперёд;
- завершить тренировку.

Причина:
- занимает лишнее вертикальное пространство;
- завершение переносится в верхнее меню управления тренировкой.

Навигация между упражнениями должна оставаться через основной интерфейс/ленту упражнений, без этой нижней панели.

## 6. Скрывать обычную шапку приложения во время активной тренировки

Когда пользователь находится внутри активной тренировки, не показывать обычный UI приложения:
- логотип/надпись GymCoach;
- переключение языка;
- переключение темы;
- кнопку выхода;
- верхнюю навигацию «Главная / История / Прогресс / Тренер / Чат / ...».

Во время тренировки экран должен быть посвящён только интерфейсу текущей тренировки.

## 7. Область применения и поведение крестика

Все требования этого плана применяются одинаково ко всем типам тренировок:
- свободным тренировкам;
- тренировкам, начатым из программы;
- любым другим активным тренировкам, которые используют этот экран.

### Крестик справа

Крестик в верхней зоне не завершает и не отменяет тренировку.

Его поведение:
- просто закрыть/свернуть экран текущей тренировки;
- вернуть пользователя на главный экран приложения;
- Session остаётся активной;
- все уже введённые данные сохраняются;
- тренировку можно позже открыть снова и продолжить с того же места;
- никаких дополнительных подтверждений для крестика не требуется.

Завершение и сброс тренировки выполняются только через меню «Управление тренировкой».

## 8. Статус реализации

Реализовано в ветке feat/free-workout-session:
- старт свободной тренировки через picker без создания пустой Session;
- атомарное создание Session вместе с первым упражнением;
- удаление технического текста из picker;
- миниатюры упражнений и fallback без изображения;
- карточка с плюсом в горизонтальной ленте;
- верхнее меню управления тренировкой с иконкой ключа;
- завершение через существующий экран итогов;
- сброс тренировки с предупреждением и 3-секундной блокировкой кнопки;
- очистка локальной offline-очереди после успешного сброса на сервере;
- удаление нижней панели «назад / завершить / далее»;
- скрытие обычной шапки/навигации GymCoach внутри активной тренировки;
- крестик работает как сворачивание: возвращает на главную и оставляет Session активной;
- поведение применяется к свободным и программным активным тренировкам.
